# Shreety’s Waiting Room 🎈

An interactive birthday celebration and countdown web application.

## Features
- **Secret Passcode Gate**: A fun knock-knock entrance screen.
- **The Door & Countdown**: Interactive door with midnight reveal and celebratory confetti.
- **Trip & Home Planners**: Customizable itinerary planner with local storage persistence.
- **Cake Catch Mini-Game**: Interactive canvas arcade game with high-score tracking.
- **Music Corner**: YouTube playlist player integration with animated vinyl and retro browser synthesizer.

## Tech Stack
- HTML5
- CSS3 (Custom Properties & Animations)
- JavaScript (Vanilla, Web Audio API, Canvas)
